# Git History 간단 문서화 - 사용 가이드

## 🎯 이 스킬이 생성하는 문서

### 포함 내용
1. ✅ **전체 요약**: 커밋 수, 개발자 수, 변경 파일 수
2. ✅ **주요 변경사항**: 관련된 커밋들을 기능별로 그룹핑
3. ✅ **커밋 상세 내역**: 각 커밋의 변경 파일과 간단한 설명
4. ✅ **개발자별 작업 내역**: 누가 무엇을 작업했는지
5. ✅ **신규 기능**: 이전 대비 새로 추가된 것들

### 제외된 내용 (불필요한 것들)
- ❌ 시간대별 통계
- ❌ 요일별 분포
- ❌ 복잡한 차트
- ❌ 디렉토리별 세부 통계

## 📝 사용 예시

### 기본 사용
```
지난 주 커밋들을 정리해줘
```

### 특정 기간
```
2025-01-15부터 2025-01-22까지의 변경사항을 문서화해줘
```

### 릴리즈 노트용
```
v1.0.0부터 v1.1.0까지 추가된 기능들을 정리해줘
```

## 🔍 스킬의 작동 방식

### 1. 커밋 데이터 수집
```bash
git log --since="2025-01-15" --until="2025-01-22" \
  --pretty=format:"%H|%an|%ad|%s" --date=short
```

### 2. 변경사항 그룹핑
비슷한 커밋들을 자동으로 묶음:
- "OAuth", "로그인", "인증" → "사용자 인증 시스템"
- "API", "엔드포인트" → "API 개발"

### 3. 신규 기능 찾기
- 커밋 메시지에 "feat:", "추가" 포함
- 새로 생성된 파일(A) 확인

### 4. 개발자별 정리
각 개발자가 작업한 기능과 파일을 요약

## 🆚 기존 버전과의 차이

### 기존 (상세) 버전
- 시간대별, 요일별 통계
- 디렉토리별 분석
- 커밋 타입별 분류
- 접이식 상세 로그
- **→ 정보가 많지만 복잡함**

### 간단 버전 (이것)
- 주요 변경사항만 그룹핑
- 개발자별 작업 내역
- 신규 기능 목록
- **→ 핵심만 간단하게**
