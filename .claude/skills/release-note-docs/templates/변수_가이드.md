# 템플릿 변수 간단 가이드

## 기본 정보

| 변수 | 설명 | 예시 |
|------|------|------|
| `{START_DATE}` | 시작 날짜 | 2025-01-15 |
| `{END_DATE}` | 종료 날짜 | 2025-01-22 |
| `{BRANCH_NAME}` | 브랜치 이름 | main |
| `{GENERATED_DATE}` | 생성 날짜 | 2025-01-25 |
| `{TOTAL_COMMITS}` | 총 커밋 수 | 23 |
| `{TOTAL_AUTHORS}` | 참여 개발자 수 | 3 |
| `{TOTAL_FILES_CHANGED}` | 변경된 파일 수 | 45 |

## 주요 변경사항 섹션

이 섹션은 여러 번 반복됩니다 (기능마다 1번씩).

| 변수 | 설명 | 예시 |
|------|------|------|
| `{FEATURE_SUMMARY}` | 전체 반복 블록 | - |
| `{FEATURE_TITLE}` | 기능 제목 | 사용자 인증 시스템 구현 |
| `{RELATED_COMMITS}` | 관련 커밋 해시들 | a1b2c3d, e4f5g6h |
| `{CONTRIBUTORS}` | 작업자 이름들 | 홍길동, 김철수 |
| `{FEATURE_DESCRIPTION}` | 변경 내용 설명 | OAuth2 기반 로그인 기능을 추가하고... |
| `{RELATED_FILES}` | 관련 파일 목록 | - src/auth/login.py<br>- src/auth/oauth.py |

## 커밋 상세 내역 섹션

이 섹션도 여러 번 반복됩니다 (커밋마다 1번씩).

| 변수 | 설명 | 예시 |
|------|------|------|
| `{COMMIT_DETAILS}` | 전체 반복 블록 | - |
| `{COMMIT_MESSAGE}` | 커밋 메시지 | feat: OAuth2 로그인 추가 |
| `{COMMIT_HASH_SHORT}` | 짧은 해시 | a1b2c3d |
| `{AUTHOR_NAME}` | 작성자 | 홍길동 |
| `{COMMIT_DATE}` | 커밋 날짜 | 2025-01-20 |
| `{CHANGED_FILES}` | 변경된 파일 목록 | - M src/auth/login.py<br>- A src/auth/oauth.py |
| `{CHANGE_SUMMARY}` | 변경 요약 | OAuth2 인증 로직 추가 |

## 사용 예시

### 주요 변경사항 채우기

**원본**:
```markdown
### {FEATURE_TITLE}
**관련 커밋**: {RELATED_COMMITS}
**작업자**: {CONTRIBUTORS}
```

**결과** (기능이 2개인 경우):
```markdown
### 사용자 인증 시스템 구현
**관련 커밋**: a1b2c3d, e4f5g6h
**작업자**: 홍길동, 김철수

### API 엔드포인트 추가
**관련 커밋**: i8j9k0l
**작업자**: 이영희
```

### 파일 목록 형식

```markdown
**변경된 파일**:
- M src/auth/login.py
- A src/auth/oauth.py
- D src/old_auth.py
```

- `M` = 수정됨
- `A` = 추가됨
- `D` = 삭제됨
